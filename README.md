# Список покупок на React

Приложение позволяет добавлять товары с названием и ценой, удалять их и видеть общую стоимость. Интерфейс адаптируется к телефону и компьютеру.

## Запуск

**Windows:** откройте `start.cmd` двойным щелчком. Скрипт найдёт установленный Node.js или подготовленную для этого окружения переносимую версию, запустит приложение и откроет его в браузере. Для остановки нажмите `Ctrl+C` в открывшемся терминале.

Обычный запуск из терминала:

Нужен Node.js 22.12+ (или актуальная LTS-версия).

```sh
npm install
npm run dev
```

Откройте адрес из терминала, обычно http://127.0.0.1:5173.

```sh
npm run build   # Сборка в dist
npm run preview # Просмотр сборки
```

## Компоненты, state и props

- `src/App.jsx` — основной компонент. `useState` хранит массив товаров. Добавление обновляет массив через spread, удаление — через `filter`. Общая стоимость вычисляется через `reduce`.
- `src/components/ShoppingItem.jsx` — отдельный компонент элемента списка. Получает товар `item`, номер `index` и обработчик `onRemove` через **props**. При нажатии кнопки передаёт родителю ID удаляемого товара.
- `src/components/AddItemForm.jsx` — форма. Название, цена и ошибка хранятся в **state**. После проверки передаёт товар в `App` через prop `onAdd`.
- `src/formatPrice.js` — форматирование цены в рублях. Цены хранятся в целых копейках, чтобы избежать ошибок при сложении дробных чисел.

Список изначально пуст. Цена поддерживает точку и запятую, до двух знаков после разделителя. Можно добавить бесплатный товар с ценой 0. Пустое название, отрицательная или некорректная цена не принимаются. После добавления форма очищается.

Данные находятся в памяти React и сбрасываются при перезагрузке страницы.
