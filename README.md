# Список покупок

React: добавление и удаление товаров, подсчёт общей стоимости.

Запуск: `npm install`, затем `npm run dev`.
Сборка: `npm run build`.

`src/App.jsx` хранит список и поля формы в `useState`.
`src/components/ShoppingItem.jsx` получает товар и функцию удаления через props.
После перезагрузки страницы список очищается.
